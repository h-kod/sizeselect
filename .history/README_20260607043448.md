# Shoe Size Widget — MVP

Files produced: React + TypeScript widget mountable as embeddable script. Build with Vite.

Run locally:

```
npm install
npm run dev
```

Build production:

```
npm run build
```

Embedding (after build):

```
<script src="https://cdn.example.com/shoe-size-widget.iife.js" data-brand="Nike" data-product-category="sneaker"></script>
```
