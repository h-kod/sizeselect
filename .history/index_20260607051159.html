Shoe Size Widget için Netlify uyumlu demo

Bu sayfa, hem widget'ı canlı test etmek hem de Netlify deploy sonrası root dizinden doğrudan kopyalanabilir bir JS embed kodu kullanmak için hazırlandı.

Netlify embed kodu

<script type="module" src="https://your-site.netlify.app/shoe-size-widget.js" data-brand="Nike" data-product-category="sneaker" data-position="after-size-selector"></script>

Deploy sonrası JS dosyası root dizinden yayınlanır ve bu kodu doğrudan başka bir sayfaya yapıştırabilirsiniz.

  • Netlify için `npm run build` + `dist`
  • Shadow DOM ile izole stil
  • Markaya göre boyut önerisi entegrasyonu
Demo ürün Modern Sneaker
Brand: Nike

Sayfada açılan Bedenimi Bul linkini kullanarak widget'ı test edebilirsiniz.

Not: Burada yaptığınız deploy sonrası Netlify, `dist/` klasöründeki `shoe-size-widget.js` dosyasını root'tan sunacaktır.
